# CNN Image Classification Using Max Pooling

## 📌 Project Overview

This project demonstrates **image classification using a Convolutional Neural Network (CNN)** with **Max Pooling** layers.

A CNN is a deep learning model commonly used for image processing and computer vision tasks. The model learns important features from images through convolutional layers and reduces the spatial dimensions using max pooling.

## 🎯 Objectives

* Understand the basics of Convolutional Neural Networks.
* Perform image classification using CNN.
* Understand the role of convolution and max pooling layers.
* Train and evaluate a deep learning image classification model.
* Analyze the model's performance on image data.

## 🏗️ CNN Architecture

The model consists of:

1. Convolutional Layer
2. Activation Function
3. Max Pooling Layer
4. Convolutional Layer
5. Activation Function
6. Max Pooling Layer
7. Flatten Layer
8. Fully Connected (Dense) Layer
9. Output Layer

### Max Pooling

Max Pooling reduces the spatial dimensions of feature maps while retaining the most important features.

For example:

```text
Feature Map
[1  3  2]
[4  6  5]
[7  2  8]

       ↓ Max Pooling

[6  8]
```
